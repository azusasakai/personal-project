AFTER HUMAN — 静的サイトパッケージ（デザイン全面再構築版）

表示方法
1. ZIPを展開します。
2. 展開したフォルダの index.html をブラウザで開きます。
   （入店前のイントロは毎回表示されます。SKIP INTRO で飛ばせます）

構成
- index.html / styles.css / script.js … ビルド不要の静的ファイル
- assets/hero/after-human-hero.png     … メインビジュアル（提供画像・無加工）
- assets/products, assets/floors       … 既存の商品・フロア写真（そのまま使用）

デザインシステム（styles.css 冒頭に記載）
黒=観察者の視点 / 骨白=保管された記録 / 桃色=標本 / 赤=分類・伏せ字
各フロアは固有色とレイアウトを持ち、商品詳細は7種のレイアウト＋5商品の専用演出で構成。

Google Fonts（Archivo / DM Mono / Noto）の読み込みにはインターネット接続が必要です。
接続できない場合は端末の代替フォントで表示されます。
